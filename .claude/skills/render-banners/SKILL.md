## Instructions

`tools/render-banners.php` is a one-shot GD script that generates 1200×630 PNG banners for every project listed in its config block. The output lands at `assets/projects/<slug>/banner.png`.

### Run it

WAMP PHP is not on PATH. Use the absolute path:

```powershell
c:/wamp64/bin/php/php8.2.29/php.exe tools/render-banners.php
```

If the path fails with "no such file", the WAMP PHP version has shifted. Find the current path with:

```powershell
Get-ChildItem c:/wamp64/bin/php
```

Update the version segment of the path and retry.

### Check before running

The script is **idempotent — it overwrites existing `banner.png` files**. Hand-edited or Gemini-generated banners get clobbered. List `assets/projects/*/banner.png` before running and confirm with the user if any look custom.

### After running

The new `banner.png` files are 1200×630, suitable for OG cards and the image sitemap. Bump the theme `Version:` (use the `bump-theme-version` skill) so `inc/auto-pages.php` re-runs and side-loads the new banners as Featured Images on the next admin pageview.

`banner-hero.png` (the wider in-page hero) is **not** generated by this script. Those are hand-supplied (currently Gemini-generated) and live alongside `banner.png` in the same project folder. If a project lacks a `banner-hero.png`, `inc/project-banner.php` falls back to the OG `banner.png` for in-page display.

### Adding a project to the script

`tools/render-banners.php` has a config block at the top mapping project slugs to motifs (hex grid, shapes, robot head, racing stripes, code glyph). To add a new project:

1. Add an entry to that config with the new slug, title, subtitle, and motif name.
2. If none of the existing motifs fit, write a new motif renderer following the pattern of the existing `draw_*` helpers.

### Past gotchas to watch for

- **UTF-8 multibyte**: use `mb_str_split()` not `str_split()` for any string with `·` or other non-ASCII glyphs. GD's font rendering byte-splits and produces mojibake (`Â·`) otherwise. Same for `mb_strtoupper()` over `strtoupper()`.
- **Motifs must not overlap the title text.** Past bug: shapes at `start_x=700, r=50` collided with "The Lost Probe" title. Push motifs to `start_x ≥ 820` and scale `r ≤ 36`.
- **Brand palette is in `theme.json`** — keep banner colors aligned to those slugs (`background`, `surface`, `primary`, `accent`, etc.) so the OG card matches the site.
